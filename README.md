# Психологические тесты (Clinical Psych Suite)

Веб-приложение для прохождения стандартизированных психологических тестов в эстетике мобильного приложения Google Gemini (темная тема, переливающийся радужный ореол, стекловидные карточки). Любой пользователь может пройти опросник анонимно и передать своему психологу защищенную ссылку с **сырыми ответами на каждый вопрос**.

## ✨ Возможности

1. **Каталог валидированных методик**:
   - **Шкала депрессии Бека (BDI-II)** — 21 вопрос с подсчетом когнитивных и соматических проявлений и подсветкой критического маркера суицидального риска (пункт 9).
   - **Шкала тревоги Бека (BAI)** — 21 вопрос с градацией тревожности и соматическими симптомами.
   - **Госпитальная шкала тревоги и депрессии (HADS)** — 14 вопросов (адаптация М.Ю. Дробижева), раздельный подсчет субшкал тревоги и депрессии (0–7 норма, 8–10 субклиника, 11–21 клинический уровень).
   - **Опросник выгорания Маслач (MBI)** — 22 вопроса по трем субшкалам (эмоциональное истощение, деперсонализация, редукция личных достижений).
2. **Интерактивное прохождение**:
   - Карточный режим (по 1 вопросу на экран с мягким автопереходом и прогресс-баром).
   - Поддержка клавиатуры (цифры 1–4, стрелки навигации).
3. **100% Анонимность**:
   - Никаких регистраций, почт или ввода личных данных.
   - Идентификация происходит по уникальному криптографическому токену сессии (`UUID`).
4. **Специальный отчет для психолога (`/report/[token]`)**:
   - **Таблица сырых ответов**: формулировка вопроса, выбранный клиентом вариант и начисленный балл.
   - **Блок Red Flags**: яркая подсветка маркеров суицидального риска и пиковых тревожных состояний.
   - **Кнопка «Скопировать для карты клиента»**: мгновенно формирует структурированный текстовый протокол для вставки в карту.
   - **Печать / Экспорт в PDF**: оптимизированный чистый макет для медицинской и психологической документации.
   - **Блок заметок специалиста**: сохраняется локально в браузере.
5. **Безопасное хранение данных**:
   - База данных SQLite (`data/tests.db`).
   - Автоматическое удаление результатов через 30 дней.
   - Кнопка немедленного удаления при необходимости.

## 🚀 Запуск проекта

### 1. Установка зависимостей (уже выполнена)
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm run dev
```
Приложение откроется по адресу [http://localhost:3000](http://localhost:3000).

### 3. Сборка и запуск продакшн-версии
```bash
npm run build
npm start
```

## 🧩 Как добавить новый тест

Каждый опросник описан декларативно в папке `src/data/tests/`:
1. Создайте файл опросника, например `src/data/tests/myTest.ts`, реализующий интерфейс `TestDefinition` из `src/types/test.ts`.
2. Задайте вопросы, варианты ответов, шкалы и функцию `calculateResult`.
3. Зарегистрируйте тест в `src/data/tests/index.ts`. Он мгновенно появится в каталоге!
